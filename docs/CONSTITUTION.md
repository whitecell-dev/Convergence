# Convergence constitution

Convergence is useful without a software factory. Its shared contract is versioned claim content plus authority transitions in Git. Evidence producers, validators, CI, models, agents, retrieval systems, dashboards, and editors are optional adapters.

For every proposed file or field in `.convergence/`, ask: **Would two independent implementations need it to agree on the current authorized claim?** If not, keep it outside the shared contract.

Evidence does not confer authority. An explicit human decision authorizes a claim; the approval reference attributes that decision. Repository governance authenticates review. A SUSPECT claim is unavailable as authority for new work.

The [protocol](PROTOCOL.md) and [file contract](file-layout.md) define conformance.
